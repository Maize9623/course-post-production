# 分屏导图与提示词适配

用于操作占主画面、侧栏呈现导图或长提示词的课程，也用于修订已有分屏。比例、字体、圆窗大小、信息密度和停留时间由项目配置及真实内容决定，不把某个项目的像素宽度、页数、字数或镜头时间码变成通用常量。仅改布局时保留已确认的口播、声音与源时钟；确需改变时长才统一重算。

## 模式与人物优先级

先明确当前段落的教学用途、文字模式与出镜状态，再选择模板。下表的人物默认值用于已有讲师素材的出镜课程；无人物模式单独记录，不为套模板生成讲师。用户明确要求优先于默认值，不能只看素材名称或渲染类型决定人物隐藏。

| 条件 | 内容显示 | 默认人物 |
|---|---|---|
| 常规图示、课名页、原文与解释配实操 | 完整主内容与必要辅助信息 | 右下圆窗可见，正文避让 |
| 用户指定完整打出、暂停详读或隐藏人物 | 实际所指原文/图，保持足够阅读时间 | 按明确要求；未另指定的完整阅读可隐藏 |
| 短提示词以合理字号可单页放下全文 | 稳定全貌，含末尾约束，随讲述标注 | 按项目阅读策略，通常隐藏 |
| 长提示词配真实操作 | 左侧实操，右侧连续原文节选、深色焦点，全文下载 | 右下圆窗可见 |
| 指定完整播片、已声明全屏实操 | 主内容独占，保留源画幅与关键内容 | 隐藏 |
| 章节核心及保护区 | 统一章卡，旁白字幕净空 | 全程隐藏 |

常规镜头应登记为“必须可见”，隐藏镜头应有原因及明确范围，不能因 cover 或 figure 模板默认关掉讲师。模板只帮助实现本次策略，不代替策略。完整文件交付不等于屏幕节选完整，屏幕节选也无需在有限时间内轮播所有原文。

## 先解决尺寸，再适配导图

以实际输出画幅和正常观看尺寸判断可读性。先调整主内容、辅助信息、可用高度与圆窗位置，再排图。两侧无法同时读清时可调整比例、先后切换或使用辅助小窗；不要把“源图没有丢”当作“学生看得清”。

1. **一层外围标题。** 面板已有题目时去掉图内重复图号、标题及对应装饰留白，保留承担知识含义的子标题、图例和结论，不能一概删掉所有标题。
2. **重组原组件。** 原件留档，正文优先使用可编辑源；栅格图可裁取原字形、线条、图标、卡片和表格组件重新组合，不拉伸文字或改写关系。必要新标签沿用相容字体并复核原意。
3. **按关系选择纵向布局。** 并列卡片可单列堆放，差异比较可上下排列，步骤可纵向推进；表格转行卡时保留列名与各值对应。并列内容不添加顺序箭头，也不强迫所有图都套同一种网格。
4. **把空间用于信息。** 去外围装饰性空白，保留必要呼吸；可放大说明、图例和总结，不通过复制句子或无关文字填满。下半栏按圆窗真实轮廓和安全边距绕行，把总结放在未遮挡位置。
5. **构图跟随内容。** 只有主图且没有侧栏信息时居中；辅助图则在实际可用区充分放大。先呈现完整结构再局部强调。所有圈线、箭头和下划线按新布局重新计算，不能套原图坐标。

记录源身份、组件对应、信息关系与标注映射。重排后的正文、最后一行、总结、图例和重点均须在真实成片里复核；制作坐标与私有 QA 图无需出现在随课资料中。

## 长提示词：真实上下文与重点

- 从可核对全文选取连续范围，包含焦点及前后相邻段落。上下文采用浅灰但可读的字，焦点用深色；不把相距很远的句子拼成连续原文。确需跳段时明确省略边界，保留语序、否定、代码与约束。
- 前面实际截去内容才显示开头省略号，后面仍有内容才显示末尾省略号。准确标为提示词或提示词节选，不用总结冒充原文，不为填版重复句子。
- 让上下文合理铺开侧栏，焦点更醒目；根据真实文字测量换行、字号、行距和段距。上方可全宽，下方避让圆窗，检查页脚、末行与字幕，不只按预计行数排版。
- 一个讲解单元内稳定显示，焦点随实际口播划线；避免闪页、逐行弹入或滚动追字。确需换页时选语义边界并给足阅读时间，不为露出全部文字快速翻页。
- 保存“原文范围 → 排版行/字 → 标注位置 → 口播帧范围”的关联，重排后重算。划线不压字，不误标邻近灰色上下文，跨行内容分段标注。
- 全文下载提醒只由一个图层负责。正确全文实际交付并核对后再提示下载，不能让底图页脚与新增提醒叠字。

## 实际成片复核

先预看本项目实际存在的代表性复杂布局，例如纵向并列、上下对比、长表格、接近圆窗的密集提示词或独立主图；无需为了凑样例创造不存在的内容。通过后再展开同类布局。

最终逐项核对全部受影响图、提示词页及标注，查看换页、人物隐藏与恢复边界。联系表用于整体状态，文字或图标读不清时查看原尺寸帧，动态标注用连续短段。核对必须可见镜头确有人物、允许隐藏段没有遮挡源画面的叠层。报告绑定新 MP4 身份并如实记录检查范围，不能用源 PNG、计划或旧版 PASS 代替新导出的实际像素。
