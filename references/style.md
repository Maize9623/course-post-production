# 可配置的视觉、人物与声音

本技能提供知识付费、理论、软件实操与混合课程的制作方法。品牌、字体、讲师位置、配乐和交付平台规范来自项目要求；assets/style.json 提供默认值，project.py init 根据 theory/practical/mixed 模式生成 project-style.json。本包工具的标准交付为 2560×1440、60 fps、48 kHz 双声道。先核对实际工具会读取哪些配置，再用于渲染、混音及核验；不能只改 JSON 就声称画幅、品牌或布局已经生效。用户明确要求优先，超出现有能力时需使用适配后的工具并重新验证。

## 视觉配置

- 本包标准输出为横屏 2560×1440、60 fps。平台若要求其他画幅或帧率，需要实际适配渲染器、时间轴与验证器，不能仅改配置宣称已支持。低帧率或低分辨率源可适配到标准输出，但不能声称恢复了原本不存在的清晰度或运动细节。
- 浅色品牌示例可使用纸色背景、白色内容面板、深色正文和少量青绿强调；已有品牌以其色板为准。原图、操作界面和实拍保留理解所需的原色，不为统一风格改变状态色、图例或事实。
- 使用本机实际可用、字形完整且授权适合交付的字体。中文可优先选择已安装的开源 CJK 字体，并配置字体回退。先测量真实字宽、混排和换行，不能靠缩小字号容纳超长标题。随包渲染器的字体发现能力需实际探测，不假设所有系统安装同一种字体。
- 字号、面板、圆窗和字幕带以输出像素或相对画幅记录，布局数值是可调整的起点；更换字体或通过其他工具适配画幅后重新测量，不能仅按比例缩放后就宣布可读。当前 render_brand.py 的 --project-style 只用于 diagram；封面、字幕条与章卡采用固定通用模板，其他品牌和几何变化需由实际合成器实现。字体使用工具实际支持的配置入口。以正常播放大小及原尺寸细节检查学生能否看清。
- 操作界面优先大、稳定、完整，保留窗口与桌面对象之间的关系。外围标题和留白不能挤小关键 UI。主图单独讲解时居中；左右分屏先保证主要操作与辅助文字都能读清，再决定比例。
- 图示先完整稳定呈现信息结构，再随口播圈选、划线或放大；并列项不画无依据的顺序箭头。重组图示及长提示词右栏详见 [split-screen-layout.md](split-screen-layout.md)。缩放和聚光只服务难读的控件或当前重点，不作为每一步的例行动画。

## 开场与讲师出镜策略

有讲师素材且采用出镜模式的课程，默认从讲师的大屏实际画面直接开场，不在问候或有效口播前添加无意的静音封面。若课程确有阶段回顾、课程地图或上下节衔接的讲述与素材，先随该段话展示阶段总览；讲师实际介绍本课名称时再显示课名页。没有阶段总览内容时跳过该环节。触发位置由剪后实际话语决定，不把某个时间码、镜头时长或自报姓名时刻写成通用规则。

以下人物策略用于已选择的出镜模式；无讲师素材或明确采用无人物模式时不制造虚构讲师，并记录该模式。常规教学默认使用右下讲师圆窗，位置和形状可由品牌或明确要求覆盖。课名页、概念图、原图、右栏提示词与分屏讲解都属于常规教学；不能因为渲染类型叫 cover、figure 或 full-canvas，就自动关闭人物。为避免重复叠加，先判断源片是否已经含有讲师小窗。

| 教学状态 | 默认人物状态 | 编排要求 |
|---|---|---|
| 问候、开场引入、结束总结 | 讲师大屏 | 用实际有效 take；需要插图时随语义切换 |
| 阶段总览、课名页、常规图示、分屏或普通录屏讲解 | 讲师圆窗可见 | 正文、总结、关键控件与字幕避让圆窗 |
| 已指定的完整播片或为看清关键细节声明的全屏实操 | 隐藏 | 源画面完整占用主内容区，见下节 |
| 指定暂停详读、单页完整提示词全貌 | 按项目要求，未另指定时隐藏 | 不让人物挡住阅读；节选配实操不套用此规则 |
| 章节卡核心及其保护区 | 隐藏 | 首末帧及恢复边界也须干净 |

为每个镜头记录“必须可见”或“允许隐藏及原因”，以及隐藏、恢复的半开帧范围。显式要求覆盖默认表格。只规定隐藏例外不够：最终成片还要反向核对每个必须可见镜头确实有讲师，尤其课名页、章节后回场和新增出镜范围。

## 完整播片

用户指定完整播放的视频素材，采用独占画面模式：隐藏讲师、右栏导图以及遮挡片源的课程叠层，保留源画幅、关键内容和应保留的来源标识。按实际素材记录起止与完整有效时长，不套用固定秒数；不得为了迁就模板裁掉播片右侧或关键 UI。必要字幕放在独立安全带或不遮挡内容的位置，是否保留源音轨按该段教学和授权决定。

播片后在已登记的口播锚点恢复讲师与课程框架。指定全屏实操同样以清楚呈现真实操作为目的，不能用隐藏人物掩盖未解决的布局问题。

## 人物抠像与去溢色

人物后期可由制作方完成，用户无需预先手工抠像。原片只读，生成独立派生文件。先核对是否已有 alpha、已替换背景或已烧入边缘瑕疵，再区分绿幕与自然背景。绿幕按实际光照和幕色选色键或分割辅助，自然背景可用人物分割；已有合成不等于仍保留完整原始前景，不能声称恢复已丢失的发丝或透明细节。

轮廓遮罩与去溢色分别调节。轮廓保留发丝、眼镜、肩线、手势和运动边缘，避免硬切、光晕、孔洞及闪烁；去溢色按实际污染区域减轻绿色反光，保护本来的皮肤、衣物颜色和明暗。不能全局去绿、过度收边或降饱和遮掩污染，也不把绿色衣物当幕布删除。检查 alpha 表示和合成顺序，避免黑边或绿边回流。

已合成画面可能含有名牌、字幕、界面标识或品牌强调色。先单独保护这些非人物叠层，再处理人物，不能仅按摄像头矩形或圆窗范围对所有像素去绿。保护范围随其真实位置、形状和有效时间变化，最终复核颜色、文字和边缘。

全片处理前，用实际素材选含头发、镜片、肩膀、浅色与深色衣物、手势的代表性短段，合成到目标背景；查看正常交付画幅、原尺寸边缘和原速短动态。全画幅及圆窗都需覆盖。记录方法、参数、源范围与判断，不沿用其他人的阈值、裁切或人脸坐标。只修人物时沿用已确认的源时钟、剪口、几何和出入场规则。

## 眼镜与镜片反光

先区分真实镜面反光、绿色溢色与抠像误把镜片/眼区变透明。反光强时检查是否已有更好的原始 take；可适度调整局部亮度、颜色和去溢色，但不能以灰块、过度模糊或错误透明度掩盖眼睛。源片过曝已经丢失的细节不能描述成已真实恢复。

需要保护镜片内的人脸时，优先采用同一讲师、同一源时刻的真实像素与局部 alpha 保护。保护区域与脸部运动、眨眼、镜框、镜腿一起跟踪，不能复制邻帧的眼睛、冻结表情或生成替代眼睛冒充真实恢复。遮罩绑定源素材身份和源零时钟，再随当前 EDL 映射到输出，不按剪后时钟错误偏移。

旧遮罩通过不代表后来新增的出镜范围也通过。每次扩大可见范围、更换 take 或调整圆窗，都检查新增源区间及其进入/退出边界；包含眨眼、转头、白衣和手势的短动态。正常源反光仍可保留，如实记录局限，不把所有反射都当成应删除的瑕疵。

## 章节与镜头

章节点按实际主题转折确定。示例配置可从约 1.3 秒核心、前后各约 0.3 秒保护区起步；帧数由项目帧率换算，实际值可覆盖。优先利用自然无词停顿，确需补时只补无词间隙，再重算声音、图示、字幕和实操时间轴。

章卡首帧至末帧以及保护区内不能出现讲师、圆窗边缘或旁白字幕。优先独立渲染不透明背景卡，内容在保护区淡退/淡入，人物在保护区之外回场。若采用人物淡变，在前保护区之前完成淡出，在后保护区之后才淡入；透明转场的底层也必须已经无人像。按真实实现区分“人物隐藏、内容淡化”和“人物本身淡变”。

若必须抹除已合成圆窗，从独立背景或可信邻域恢复底图，验证原圆内全部像素与边缘色差，不能只抹脸中心。普通内容交叠时维持同一条讲师源时钟，避免两个头像、中间全画幅闪帧或嘴型跳动。镜头节奏由论点、动作和阅读需要决定，不使用固定切镜频率。

## 声音和字幕

- 本包声音母版采用 48 kHz 双声道，与 60 fps 标准时间轴配合。响度、BGM 系数和包络按工具支持的项目参数及目标平台规范调整；采样率或声道变更需实际适配工具和验证。跨课一致性依据 LUFS、真峰值和主观听感，不依据麦克风音量百分比，详见 [audio-loudness.md](audio-loudness.md)。
- 背景音乐由用户指定或在许可范围内选择，不固定歌曲。线性幅度系数不是 dB、LUFS 或人声响度比例；先校准人声再混合。音乐浮点解码保留源峰值，循环使用互补权重，淡入淡出与闪避包络需实测，不通过整片提响无意抬高 BGM。
- 口播保持原速、原音高。响度校准优先保持自然起伏，峰值确实阻碍目标时再做必要保护，并记录实际处理。气声与底噪的判断和处理见 [audio-cleanup.md](audio-cleanup.md)，不重复处理已认可的音源。
- 字幕从剪后实际讲话生成，按完整语义断句，保留主谓、否定、条件与因果关系。超宽句先按语义拆分，不机械逐词切换或不断缩字号。专有名词以稿件与真实界面核对，未说的句子不补入；中英混排保留必要空格，代码、路径和命令不盲目改写。
- 烧入字幕、SRT 与字幕 JSON 来自同一份最终文本。按局部明暗选择对比清楚的字色与必要描边，检查句尾、末行、章卡净空和圆窗避让，不包含制作内部标签。
