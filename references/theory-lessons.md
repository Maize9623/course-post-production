# 理论课编排

把稿件、导图与实际讲话整理为学习目标、论证关系和逻辑段，再对齐剪后口播。概念图、案例、真实视频和讲师表达共同服务理解；不按固定视频占比、切镜频率或每段一条 B-roll 的配额凑表现力。品牌、人物与画幅见 [style.md](style.md)。

## 结构与开场

有讲师素材并采用出镜模式时，默认由讲师大屏直接引入问题。若内容确实涉及阶段回顾或课程地图，随讲述先展示相应总览；介绍本课名称时再显示课名页，触发时间来自实际口播。没有阶段回顾时不补造一个环节。普通图示和课名页按项目策略保留讲师圆窗，不能因满幅图卡自动隐藏人物。

让学生知道主要问题、为什么值得学、将如何理解或应用。前后段落以论点和案例自然衔接；重复强调有教学作用时保留，不因文字相同机械去重。

## 图示与信息关系

- 因果图说明输入、机制与结果；并列分类不增加顺序箭头；差异采用前后或双栏；体系采用分层；循环仅在确有反馈关系时使用。
- 图中数字来自可靠资料或明确的教学示意，不凭空生成统计、成本或性能数据。生成视觉不能冒充实际发生的事实。
- 原图逐项登记原文、源身份、讲解区间、全图位置和重点。复杂图先交代完整结构，再随口播放大、平移或高亮，最后按需要回到整体。
- 重排原组件时保留字形、图标、标签、关系与总结，去掉与外围面板重复的内部标题。只有主图时居中；右侧辅助图按 [split-screen-layout.md](split-screen-layout.md) 适配，而不是把横图缩成角落缩略图。
- 图示动效表达实际关系，不能把单句包装成伪交互，或将并列关系画成因果。稳定阅读足以讲清时，无需装饰动画。

## 视频、案例与播片

优先采用用户素材、自制案例和许可范围内可用的视频。记录源文件、使用区间、语义用途与使用次数；换速度、裁切或颜色不算新内容。同一文件中的不同内容可以独立使用，重复播放同一动作或品牌片头不能冒充新镜头。

画面可展示真实工作场景、作品结果、演示、流程或新旧 UI 对比。讲具体操作方法或实际效果时使用核实过的操作或可靠证据；示意性生成画面需标明其性质，不作为真实结果的证明。禁止静态照片推拉冒充动态混剪。

用户指定完整播放的视频素材时，按 [style.md](style.md#完整播片) 保留真实完整时长，独占主画面并隐藏会遮挡源片的讲师与右栏。普通短案例可以按语义截取，但源内容和截取性质需准确记录。播片不打断关键推理，也不侵占后续图示阅读。

素材不足时先看稳定图示或讲师表达是否已能讲清；确需补视频再在可用能力和授权范围内补足。没有生成能力不能声称生成完成，不循环短片撑满课程。

## 语义与画面复审

检查主要结论是否获得相应解释或证据，原图信息是否完整，箭头与对比是否成立，来源和标签是否准确，学生能否理解本段与前后段的联系。逐镜核对讲师可见/隐藏状态，尤其开场、课名页与播片恢复；对重点文字和关系查看实际 MP4 原尺寸画面。技术通过但教学失配的段落仍需修订，详见 [delivery-and-qa.md](delivery-and-qa.md)。
